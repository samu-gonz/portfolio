# Portfolio Full-Stack (Next.js + Tailwind + Framer Motion)

Portfolio profesional con experiencia inmersiva de introduccion y dashboard interactivo tipo Single Screen UI.

## Stack

- Next.js (App Router)
- React
- Tailwind CSS
- Framer Motion

## Requisitos

- Node.js 18+ (recomendado 20+)
- npm

## Instalacion y ejecucion

```bash
npm install
npm run dev
```

Abrir en navegador: `http://localhost:3000`

## Scripts

- `npm run dev`: entorno de desarrollo
- `npm run build`: build de produccion
- `npm run start`: ejecutar build
- `npm run lint`: lint del proyecto

## Estructura principal

```txt
app/
  layout.jsx
  page.jsx
components/
  IntroSequence.jsx
  HeroSection.jsx
  BentoGrid.jsx
styles/
  globals.css
```

## Objetivo del proyecto

Demostrar seniority tecnico y enfoque de conversion B2B mediante:

- Introduccion animada con zoom inmersivo al entorno de desarrollo.
- Dashboard interactivo de pantalla unica.
- Casos de estudio internos con enfoque de negocio.
